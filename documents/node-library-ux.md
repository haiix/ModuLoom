# ノードライブラリのパレット設計

## カタログとパレットの責務

「すべてのノード」は登録済み定義の完全なカタログです。Core / Advanced / Examples / Project の
分類、機能カテゴリ、検索を維持し、パレット設定にかかわらずすべての定義へ到達できます。

カタログの前には、現在の作業に合わせたショートカットを表示します。

| セクション               | 内容                                       | 並び順                          |
| ------------------------ | ------------------------------------------ | ------------------------------- |
| 接続可能候補             | 選択したポートと接続できる定義（最大12件） | 型の完全一致、`any`互換、名前順 |
| パレット                 | ユーザーが星印でピン留めした定義           | ピン留め順                      |
| 最近使ったノード         | ライブラリから追加した直近8種類            | 最終使用順、重複なし            |
| このプロジェクトで使用中 | キャンバス上にあるノードの種類             | 最初に現れる順、重複なし        |
| このプロジェクト固有     | 自作、カスタム型由来、複合ノード           | 定義の登録順                    |

同じ定義が複数セクションに現れることを許容します。削除済みの自作定義など、現在登録されて
いないIDは設定に残っても表示せず、完全なカタログの利用を妨げません。

## 保存スコープと初期状態

ピン留めと最近使用は Local Storage の `moduloom:node-palette-v1` に保存します。プロジェクトJSON、
自動保存スナップショット、Undo履歴には含めません。同じブラウザではプロジェクトをまたいで
利用できますが、別ブラウザや別端末へは同期しません。

初期パレットと最近使用は空です。設定がない、壊れている、またはStorageが利用できない場合も
空の状態から開始し、「すべてのノード」とProjectは常に利用できます。最近使用はノードを実際に
追加したときだけ更新し、プロジェクトを読み込んだだけでは更新しません。

## 操作フロー

- 星印を押すとパレットへ追加し、もう一度押すと外します。
- どのセクションから追加しても最近使用の先頭へ移動します。
- 検索中はショートカットの重複を隠し、完全なカタログを絞り込みます。
- 入出力ポートをクリックするか、フォーカスして `Enter` / `Space` を押すとライブラリを開き、
  接続方向と実効型に合う候補を表示します。候補の追加後も選択を維持します。
- フォームへ入力中でないとき `/` を押すとライブラリを開き、検索欄へ移動します。

候補の型判定は実際の接続と同じ規則を使います。出力選択時は互換入力を持つ定義、入力選択時は
互換出力を持つ定義を対象にし、カスタム型から `object` への接続も含めます。候補から追加した時点
では自動接続せず、ユーザーが配置と接続先ポートを確認してから接続します。

## ワイヤーフレーム

```text
┌─ ノードライブラリ ─────────────────┐
│ [検索 ______________________]       │
│ 接続可能候補: value (number)  [×]   │
│   Add                         [☆]   │
│ パレット (2)                        │
│   Number                      [★]   │
│ 最近使ったノード (3)                │
│ このプロジェクトで使用中 (4)         │
│ このプロジェクト固有 (1)             │
│ ─ すべてのノード ─                  │
│ ▼ Core / ▶ Advanced / ...           │
└─────────────────────────────────────┘
```

767px以下では画面左右に8pxずつ余白を残してライブラリを広げます。高さはツールバーを除く画面内に
制限し、内容だけをスクロールします。閉じた状態は従来どおり左上の48pxボタンです。

```text
┌──────── 狭い画面 ────────┐
│ [上部ツールバー]          │
│ ┌──────────────────────┐ │
│ │ ノードライブラリ      │ │
│ │ [検索______________] │ │
│ │ パレット / 最近 / ... │ │
│ │ すべてのノード        │ │
│ └──────────────────────┘ │
│        キャンバス         │
└──────────────────────────┘
```

## 既存設定の移行

従来の開閉設定 `moduloom:node-library-open` はそのまま利用します。カテゴリとセクションの
折りたたみはコンポーネント内だけの一時状態で保存形式を持たないため、移行データはありません。
新しい設定はバージョン付きの別キーにし、未知の旧形式は空設定へ安全にフォールバックします。
Core / Project 展開、Advanced / Examples 折りたたみという既定値は維持します。

## アクセシビリティ

- 検索、追加、ピン留め、折りたたみ、候補解除、ポートはキーボードで操作できます。
- ピン留めは色や星形だけに依存せず、操作名と `aria-pressed` で状態を伝えます。
- セクションの展開状態は `aria-expanded`、件数は見出しテキストで伝えます。
- ポートには方向、名前、型、候補表示という操作目的を含むラベルを付けます。
- `/` は入力欄や編集可能要素では発火せず、文字入力を妨げません。
- Local Storageが無効でも全件カタログ、検索、Project定義を利用できます。
