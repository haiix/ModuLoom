# サンプルギャラリー設計

## 自己完結形式

サンプルは `GraphPreset` として、グラフに加えて次の表示情報と依存物を同梱します。

| フィールド                       | 内容                                                       |
| -------------------------------- | ---------------------------------------------------------- |
| `difficulty`                     | `beginner` / `intermediate` / `advanced`                   |
| `tags`                           | Math、Async、Stream、Custom Type、Composite などの検索タグ |
| `learningGoals`                  | サンプルから学べる内容                                     |
| `expectedResult`                 | 初期値で実行したときに確認できる結果                       |
| `dependencies.customTypes`       | グラフが使用するカスタム型                                 |
| `dependencies.customDefinitions` | グラフが使用する自作・複合ノード定義                       |

組み込みノードはアプリ本体から解決し、サンプルに複製しません。ギャラリーは使用しているノードの
種類数と総数、追加されるカスタム型を表示します。

## 開く・挿入・競合解決

「新規として開く」は現在のノード、接続、カスタム型、自作・複合ノード定義をサンプル一式へ
置き換えます。現在内容がある場合は置換対象を確認し、適用後は1回のUndoで元へ戻せます。

「挿入」は現在の内容を維持し、表示中のキャンバス中央付近へサンプルを追加します。ノードIDと
接続IDは毎回再採番するため、同じサンプルを複数回挿入できます。依存物は次の規則で解決します。

- 同じIDがなければプロジェクトへ追加する。
- 同じID・同じ内容なら既存定義を再利用する。`catalogSource` は表示用メタデータのため比較から
  除外し、旧プロジェクト由来で未設定の場合だけサンプル側の値を補完する。
- 同じIDで内容が異なる場合は、既存プロジェクトを暗黙に変更せず挿入を中断し、競合名を表示する。

競合時の名称変更や上書きは、参照する `typeId` も一括変更する必要があるため現段階では行いません。
新規として開く場合は独立したプロジェクト扱いなので競合は発生せず、サンプル同梱の依存物だけを
使用します。

## User / Point2D の扱い

新規プロジェクトはカスタム型を持たない状態で開始します。教材用の `User` は「カスタム型」
サンプル、`Point2D` は「2Dベクトル長」サンプルの依存物としてのみ取り込みます。後者は
Point2Dを生成・分解した座標から長さを計算するため、どちらの型も選択したサンプル内で実際に
使用されます。既存プロジェクトに保存済みの型は従来どおり読み込み・評価できます。

## 既存サンプルの整理

| サンプル                | 難易度 | 主なタグ                       | 依存物    | 想定結果                     |
| ----------------------- | ------ | ------------------------------ | --------- | ---------------------------- |
| 四則演算パイプライン    | 入門   | Math、Input、Output            | なし      | `12 × 8 + 15 = 111`          |
| 動的文字列テンプレート  | 入門   | String、Template               | なし      | 大文字メッセージと文字数     |
| 年齢チェック・条件分岐  | 入門   | Logic、Branch                  | なし      | 年齢21を成人判定             |
| 配列データ変換          | 中級   | Array、Filter、Map             | なし      | 合計178とCSV                 |
| User生成・検証・分解    | 中級   | Custom Type、Validation        | `User`    | 検証済みUserの氏名とメール   |
| Promise・疑似API        | 上級   | Async、Promise                 | なし      | レスポンスとmetrics          |
| AsyncIteratorストリーム | 上級   | Stream、Filter、Map            | なし      | `[0, 20, 40, 60, 80]`        |
| 2Dベクトル長            | 上級   | Composite、Point2D             | `Point2D` | 3と4から5                    |
| 10倍部分適用            | 上級   | Composite、Partial Application | なし      | 引数を10倍する複合ノード候補 |

疑似APIは実ネットワーク通信を行わない教材ノードです。ギャラリーのタグと説明でその点を明示します。

## 導線ワイヤーフレーム

```text
その他の操作
└─ サンプルギャラリー
   ┌──────────────────────────────────────────────────┐
   │ サンプルギャラリー                         [閉じる] │
   │ [タイトル、学べる内容、タグから検索____________] │
   │ ┌────────────────┐  ┌────────────────┐           │
   │ │ グラフプレビュー │  │ グラフプレビュー │           │
   │ │ タイトル  [難易度]│  │ タイトル  [難易度]│           │
   │ │ 説明／学習内容   │  │ 説明／学習内容   │           │
   │ │ 想定結果／依存物 │  │ 想定結果／依存物 │           │
   │ │ [新規で開く][挿入]│  │ [新規で開く][挿入]│           │
   │ └────────────────┘  └────────────────┘           │
   └──────────────────────────────────────────────────┘
```

複合化モーダルの「10倍関数」「2Dベクトル長」導線は、ギャラリーにも同じ2サンプルを掲載して
相互参照できる状態にします。モーダル側の短い導線は、出力端子がない状況から直接挿入する用途の
ため維持します。

ダイアログは開いたとき検索欄へフォーカスし、`Escape` で閉じられます。カード内の操作は通常の
ボタンとしてキーボードから利用でき、グラフプレビューには代替テキストを付けます。狭い画面では
カードを1列にします。
